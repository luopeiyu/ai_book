# 战斗模拟器系统


回合制战斗模拟器，支持3v3队伍对战，包含多种技能和状态效果。
出于实验难度考虑，系统采用确定性方案，相同输入产生相同结果。


队伍配置
  - 每队3个英雄
  - 每个英雄有1个固定技能
  - 每个英雄有1个可选技能（从18个技能中选择）
  - 英雄ID范围：0-39（40个英雄）
  - 技能ID范围：0-17（18个技能）


最大回合数
  - 超过50回合判定为平局


英雄属性
  - 生命值 (HP)：当前血量/基础血量，归零时英雄死亡
  - 攻击力：基础攻击力，影响物理伤害计算
  - 防御力：基础防御力，减免受到的物理伤害
  - 速度：决定回合行动顺序，可被状态效果修改

伤害计算
  - 基础伤害 = 攻击者有效攻击力 * 技能伤害倍数
  - 最终伤害 = max(0, 基础伤害 * 克制修正系数 - 受击者当前防御力)
  - 有效攻击力 = 当前攻击力 * 蓄力倍数
  - 克制关系和系数见 damage_constants.py

技能
  - 技能池见 skill_pool.py

英雄
  - 英雄池见 hero_poool.py
  
使用方式
  - test.py 直接调用战斗模拟器进行测试
  - main.py 开启http API，api定义见该文件
