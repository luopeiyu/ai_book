# AI重塑游戏开发 书籍代码资源

《AI重塑游戏开发：让NPC“活”起来》是一本是游戏研发与人工智能结合的实战指南，选取热门游戏产品中的多个AI案例，内容涵盖智能NPC、AI捏脸、平衡性分析、关卡生成等多个前沿领域，展现AI技术在现代游戏开发中的应用场景。  

通过案例，掌握AI技术，探求AI在游戏应用的一般性方法，适合有志于入门AI领域并将AI技术应用到生产的游戏开发者，也适合有志于进入游戏行业的AI工程师。

## 为什么要写这本书  

进入AI时代，游戏开发技术正在经历深刻变革，AI必将给游戏行业带来巨变。  

在2017年之前，作者就一直关注AI与游戏的结合场景，例如在知乎开设《自动做游戏：AI技术落地于游戏开发》的文章专栏，也在工作中做了很多摸索。2022年末，随着AI绘图Stable Diffusion和语言模型ChatGPT的成熟，游戏行业掀起一波AI浪潮，各家游戏公司多多少少都会用AI来提效。尽管几乎所有从业者都看好AI，但由于AI投入很大且落地场景不很明确，时至今日也只有大厂能够持续投入。  

如何将AI技术更好的落地于游戏研发场景，从业者都在摸索，作者也在摸索中总结经验。我们看到市面上已有一些很有价值的实际应用，包括AI捏脸、关卡生成等等，如果能将这些案例串联起来，形成知识体系，或能抛砖引玉，为游戏从业者的下一步的探索提供可参照的材料。  

偶尔会有朋友来问我，说自己很想接触AI，但磕磕碰碰不知道怎么入门。光看理论的作用不太大，就像自己当年学编程时，要动动手才能理解深刻，市面上的游戏AI资料，要不就是着重讲机器学习算法、神经网络原理这些理论知识，但缺乏与游戏场景的深度结合；要不就是很务虚地介绍大模型怎样驱动游戏开发，但大多是没有历经实践的美好想象。  

AI发展很快，作者自己也是摸着石头过河。虽未知AI游戏的终点是何种形态，但未来的曙光在召唤我们，必须时刻准备着。本书也作为一个阶段性总结，将作者多年在游戏AI领域的探索经验全盘托出。期望能够形成一本既实用、深入浅出的教程，为游戏行业的AI技术普及和创新发展添砖加瓦。  

某种意义上说，从早年开设的知乎专栏《自动做游戏：AI技术落地于游戏开发》起，作者就一直在为本书的出版做铺垫。2022年发表于UWA的长文《直观理解AI博弈原理》是一次尝试，2023年开始为本书整理素材，2024年3月规划了本书第一版目录，至2025年6月确定了最终的目录大纲。由此追溯，也算是规划多年的作品。  

对于游戏开发者，AI技术就像一把利刃，让我们有机会在较为成熟的游戏客户端和服务端的开发技术之上，划破黎明晨光，迎接下一波浪潮。  

## 如何阅读本书
通过本书，读者可以从零开始学习AI基础知识，并将所学内容应用到实际研发场景之中。本书主要分为三大部分。  

第一部分：基础建模。介绍PyTorch AI模型开发的基础知识，并通过玩家战斗力预测和AI照片捏脸的案例介绍监督学习在游戏场景中的应用。涉及数据收集、模型训练、训练图像分类模型等内容。  

第二部分：强化学习。介绍Stable Baseline3强化学习的基础，通过关卡生成案例介绍使用AI强化学习技术生成符合特定难度要求的三消游戏关卡。  

第三部分：综合应用。介绍智能NPC、阵容挖掘和阵容推荐、视频动作生成等案例，希望能够抛砖引玉，激发读者对AI落地的更多灵感。  

本书虽以Python和Unity为主要开发环境，使用PyTorch和Stable Baseline3框架，但更重要的是探求AI技术在游戏开发中的一般性方法，因此它同样适用于使用不同技术栈的项目。同时，由于AI技术需要结合实际游戏场景，因此本书除了介绍AI算法的内容，也会包含一部分Unity和Python的游戏业务开发向的内容，用于为AI算法提供可运行的环境。
